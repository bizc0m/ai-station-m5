# BDSM 18+ consensuel - Prompt Pack

## Cadre

Usage : image adulte stylisee dans ComfyUI, avec adultes clairement 18+, consentement clair, rendu editorial/photo de mode.

Interdit : mineurs ou apparence mineure, contrainte reelle, violence sexuelle, blessure, sang, coercition, humiliation non consentie, deepfake ou personne reelle sans accord.

## Workflow conseille

- Service : ComfyUI
- Modele de base : `sd_xl_base_1.0.safetensors`
- Alternative test rapide : `z_image_turbo_bf16.safetensors`
- Upscale : `4x-UltraSharp.pth`
- Taille portrait : `832x1216`
- Taille carree : `1024x1024`
- Sampler : `DPM++ 2M Karras` ou `Euler a`
- Steps : `28-36`
- CFG : `5.5-7`
